# Обґрунтування вибору моделі (Крок 11)

## 1. Порівняння кандидатів
На етапах тестування та вимірювання циклу (крок 08) було зіставлено три середовища:
1. **Google Gemini 2.5 Flash** (хмарний вендор, Chat Completions): відмінне слідування схемі Zod, впевнене викликання інструментів, низька вартість ($0.15 / $0.60 за 1M токенів).
2. **Claude 3.5 Haiku / OpenRouter** (шлюз, Messages API): швидка генерація, суворе слідування структурі, але вища ціна.
3. **Qwen 2.5 Coder 1.5B** (локально, Ollama): нульова грошова вартість, висока швидкість на легкому коді, але схильність до циклічних помилок без явного зразка JSON у промпті.

## 2. Фінальне рішення для продакшену
- **Обрана модель**: `gemini-2.5-flash` (резерв: `claude-3-5-haiku`).
- **Підстава вибору**:
  - Надійність структурованого виходу: 100% проходження перевірки Zod на фінальному кроці.
  - Економічність: вартість одного повного сеансу на задачі `/api/health` склала лише $0.000688.
  - Життєвий цикл: дата зняття з підтримки вендором (`retiresNotBefore`) визначена після 2027 року, що гарантує стабільність рішення після захисту лабораторної.
