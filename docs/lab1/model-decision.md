- **Модель «ДО»**: `qwen2.5-coder:7b` (локально через Ollama).

## 3. Чому замінили та оцінка ризиків
1. **Причина заміни**: локальна 7B модель на процесорі потребує 80 секунд на прогін із 2 кроків, а OpenRouter — 46 секунд. Хмарний прямий ендпоінт Gemini повертає верифікований результат за 10 секунд.
2. **Оцінка ризиків**:
   - **Життєвий цикл (`retiresNotBefore`)**: у `src/models.ts` дата встановлена на `2027-04-01` (та `2027-06-01` для Gemini), що гарантує доступність моделі довше за дату захисту курсової.
   - **Політика даних**: для конфіденційних задач використовується локальна Ollama, а для CI/CD та швидких тестів — хмарний ендпоінт.
