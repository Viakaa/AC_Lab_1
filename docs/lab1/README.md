## 2. Деталізація за кроками

### Кроки 01–02: Налаштування та режим планування
- Створено файл `AGENTS.md`, у якому зафіксовано правила роботи та межі інструментів.
- Перевірено поведінку обох агентів у режимі планування:
  - **OpenCode**: адаптовано через конфігурацію `opencode.json` (режим `Plan` з обмеженням `edit: deny`).
  - **Copilot CLI**: використано вбудований plan-режим із застосуванням патчів у внутрішній стан сесії.

### Крок 03: Журналювання дій (Audit Log)
- Для **OpenCode** реалізовано плагін `.opencode/plugins/agent-log.js` (подія `tool.execute.after`).
- Для **Copilot CLI** налаштовано хук `.github/hooks/agent-log.json` та скрипт `scripts/agent-log-hook.mjs`.
- Усі дії фіксуються в уніфікованому форматі JSONL у директорії `.agent-log/`.

### Крок 04: Навичка (Skills)
- Реалізовано навичку додавання маршруту API відповідно до специфікації `agentskills.io`.
- Обидва агенти успішно зчитують контракти та викликають скрипти перевірки маршрутів.

### Крок 05: Заборона доступу (Pre-tool Guard)
- Налаштовано блокування доступу до файлів конфігурації оточення (`.env*`):
  - **OpenCode**: плагін перехоплення `guard-env.js` з помилкою блокування.
  - **Copilot CLI**: скрипт перехоплення повертає `permissionDecision: "deny"`.
- Фіксація відмов: спроби доступу реєструються в журналах із позначкою `"result": "denied"`.
