# Вимірювання вартості контексту MCP (Context7)

## Базова лінія та вартість сервера

| Сервер | До | Після | Навіщо |
|---|---|---|---|
| context7 | не вимірюється | не вимірюється (~2000–3000 символів у відповіді) | Надає актуальну документацію фреймворків (Next.js App Router, Route Handlers тощо) без галюцинацій та застарілих API |

## Примітки та висновки
1. У GitHub Copilot CLI та OpenCode вбудована команда детального вимірювання заповнення контекстного вікна (`/context`) відсутня. Оцінка проведена за розміром поверненого контексту інструментами `context7_resolve-library-id` та `context7_query-docs`.
2. Головна ціна MCP-сервера в контексті — це розмір сторінки документації, яка додається до історії діалогу й передається у кожен наступний запит сесії.
