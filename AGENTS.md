# AGENTS.md

Програма яка використовує Playwright для тестування, але LLM вирішує що саме провірити по ходу тестування і записує баг репорти

## Стек

- TypeScript (strict), Next.js (App Router), Vitest, Playwright.

## Команди

- `npm run doctor` — перевірка середовища та стану агентів
- `npm run dev` — запуск локального застосунку
- `npm test` — тести (Vitest), без мережі.
- `npm run typecheck` — перевірка типів, без емісії.
- `npm run lint` — лінтер.
- `npm run build` — продакшн-збірка.
- Обов'язково перед «готово»: `npm run typecheck && npm run lint && npm test`.

## Межі

- `.env` і `.env.local` агент не читає і не редагує: секрети веде людина.
- `test-results/` та `playwright-report/` дозволено читати для дебагу, але заборонено редагувати
- `package-lock.json` і `.agent-log/` не редагувати вручну
- Юніт-тести не ходять у мережу і не викликають платні API.
- E2E звертаються лише до локального сервера й до моделі 
- `git push`, зміна залежностей, видалення коду чи файлів - лише після підтвердження людини


## Домовленості

- Модель обирається роллю з `src/models.ts` (`MODELS.cheap`), а не рядком-ідентифікатором.
- Ціни й дати зняття моделей звіряються зі сторінкою вендора, а не з пам'яті.
- Формат комітів: `feat:`, `fix:`, `test:`, `refactor:`, `docs:`, українською.
- Немає any
